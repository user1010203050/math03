# High-Precision Function Generator & Statistical Delta Analyzer

A highly optimized mathematical utility developed in C++ to generate, compute, and analyze discrete linear function telemetry. The core logic handles values starting from 1 up to a strict maximum constraint of 100.

Unlike standard calculators, this program features a specialized **Statistical Aggregation Engine** that monitors iterative difference variables (Delta tracking), compiles them into memory arrays, and outputs a clean, spam-filtered analytical report.

---

## ⚡ What This Program Can Do (Key Capabilities)

* **Linear Telemetry Generation:** Computes function limits dynamically between 1 and 100 using precision `float` datatypes.
* **Continuous Multi-Layer Trajectory:** Executes deeply nested logical loops to simulate arithmetic progression and patterned recursive resets.
* **Successive Delta Monitoring:** Evaluates the exact instantaneous change (`f(k) - f(k-1)`) for every standalone frame or calculation step.
* **Aggregated Statistical Reporting:** Automatically tracks how many times a specific Delta value occurs across thousands of computations.
* **Spam-Filtered Output Matrix:** Suppresses redundant null results (zeros) and isolates the final analytical data for absolute clarity and high-speed processing.

---
## ⚙️ Runtime Parameters & Sequential Logic Dependencies

The console interface evaluates user choices instantly via a strict **Sequential Dependency System**. Advanced features remain locked unless the preceding parameters are fully activated (Set to `1`). To unleash the full analytical power of the engine, all parameters must be sequentially approved:

1. **Enter the number:** Sets the operational boundary constraint for the data loops (e.g., `5`).
2. **You want integer (Enter 1 / 0):** 
   * `1`: Enforces strict integer type-casting (`int(f)`).
   * `0`: Preserves floating-point decimal accuracy. *(Note: Choosing '0' here limits the output to standard telemetry blocks, bypassing advanced counter matrices).*
3. **Are want f2-f1 (Enter 1 / 0):** 
   * Must be set to `1` (and preceded by `1` in step 2) to activate dynamic differential calculations.
4. **Counter f2-f1 (Enter 1 / 0):** 
   * The final analytical tier. Activating this via `1` triggers the memory array to aggregate, register, and print the cumulative statistical report at the end of execution.
